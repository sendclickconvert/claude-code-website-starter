# 04. Check your site

**What this does:** Claude Code checks its own work against the rules, and lists every problem it finds. You still check with your own eyes afterwards.

**Copy and paste this into Claude Code:**

```
Check every page of this website against CLAUDE.md and list every problem you find. Check:

- Any fact that isn't in CLAUDE.md (phone, address, hours, prices, claims, reviews)
- The business name, phone and address written exactly the same everywhere
- Exactly one H1 per page
- Page titles 60 characters or fewer, descriptions 155 or fewer
- Every link and button goes somewhere real
- The phone number is a tap-to-call link
- How it looks at phone width

Don't fix anything yet. Just give me the list.
```

**What to expect:** a list. Read it. Anything that's a made-up fact gets fixed first.
