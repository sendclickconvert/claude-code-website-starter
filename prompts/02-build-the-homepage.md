# 02. Build the homepage

**What this does:** Claude Code builds the one-page website from the plan you just agreed.

**Copy and paste this into Claude Code:**

```
Build the one-page website we just planned, following every rule in CLAUDE.md.
Only use the facts in CLAUDE.md. If something is missing, ask me instead of inventing it.

When you're finished, tell me exactly how to open it in my browser.
```

**What to expect:** Claude Code may ask permission to create files. That's normal. When it's done, open `index.html` in your browser (double-click it, or follow what Claude Code tells you).

It won't be perfect on the first try. Nobody's is. Tell it what to change in plain words: "Make the phone number bigger", "Move the services above the about section", "This colour is too dark".
