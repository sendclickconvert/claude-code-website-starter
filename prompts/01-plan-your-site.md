# 01. Plan your site

**What this does:** Claude Code reads your business facts and tells you what it plans to build *before* it builds anything. You catch mistakes while they're still cheap.

**Copy and paste this into Claude Code:**

```
Read CLAUDE.md. Then, before you build anything, tell me:

1. Which business facts you have, and which ones are missing.
2. What sections you'd put on a one-page website for this business, in order, and why.
3. What the main heading (H1) and the page title would say.

Don't create any files yet. Ask me about anything missing.
```

**What to expect:** a short plan and a few questions. Answer them, and fix any fact it got wrong in `CLAUDE.md` first.
