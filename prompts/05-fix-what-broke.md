# 05. Fix what broke

**What this does:** fixes the problems from the check, one at a time, and turns each one into a rule so it doesn't come back.

**Copy and paste this into Claude Code:**

```
Fix the problems you found, one at a time. After each fix, tell me what you changed and how I can see it.

Then add a short rule to the "Mistakes we've fixed" section of CLAUDE.md for each problem,
so it doesn't happen again in a future session.

Finally, update "Where we left off" in CLAUDE.md with what's done and what's next.
```

**What to expect:** your `CLAUDE.md` gets smarter every time you do this. That's the habit that makes Claude Code better week after week.
