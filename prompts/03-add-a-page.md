# 03. Add a page (only when you need one)

**What this does:** adds a second page, for example a page for your most important service, without breaking the first one.

Most small businesses don't need ten pages on day one. Add a page when a service is big enough to deserve its own, or when customers keep asking about one thing.

**Copy and paste this into Claude Code, and change the part in brackets:**

```
Add a new page for [the service, e.g. "emergency plumbing"].
Follow every rule in CLAUDE.md. Use only facts from CLAUDE.md, and ask me for anything missing.
Link to the new page from the homepage, and link back to the homepage from the new page.
Use the same header, footer, phone number and style as the homepage.
```
