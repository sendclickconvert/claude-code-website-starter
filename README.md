# Claude Code Website Starter

**Build your first website with Claude Code, even if you've never written a line of code.**

This is a free starter kit for people who want to build a real website for a real business, by describing what they want in plain English. You drop this folder on your computer, open Claude Code inside it, and paste the prompts in order. Claude Code does the building. You make the decisions.

## What's in the box

| File | What it does |
|---|---|
| [`CLAUDE.md`](CLAUDE.md) | The rules Claude Code reads at the start of every session. You fill in your business facts once, and it stops guessing. |
| [`prompts/`](prompts/) | Five prompts to paste in order: plan, build, add a page, check, fix. |
| [`checklists/before-you-go-live.md`](checklists/before-you-go-live.md) | What to check with your own eyes before anyone sees the site. |

There's no website in here yet. That's the point. Claude Code builds it with you, from your facts.

## How to use it

**1. Get the folder onto your computer.**
Click the green **Code** button at the top of this page, then **Download ZIP**. Unzip it and rename the folder after the business, for example `joes-plumbing`.

**2. Fill in `CLAUDE.md`.**
Open it in any text editor (Notepad is fine). Replace everything in `[square brackets]` under "About this business" with real facts. Leave anything you don't know blank. Claude Code will ask instead of making it up.

**3. Open Claude Code in that folder.**
In the terminal, go to the folder and type `claude`. Or open the folder in the Claude desktop app or VS Code.

**4. Paste the prompts in order.**
Open [`prompts/01-plan-your-site.md`](prompts/01-plan-your-site.md), copy the prompt, paste it into Claude Code. Answer its questions. Then move to the next one.

**5. Check it yourself.**
Claude Code will tell you when it's done. "Done" isn't proof. Open the page, click every button, try it on your phone. Use the [go-live checklist](checklists/before-you-go-live.md).

## The two habits that matter

**It forgets.** Every session starts fresh. That's why `CLAUDE.md` exists: it's the first thing Claude Code reads every time. When it makes a mistake, add a rule to `CLAUDE.md` so it doesn't happen again. ([Claude Code memory and CLAUDE.md](https://launchwithbryan.com/blog/claude-code-memory?utm_source=github&utm_medium=repo))

**Never let it invent business facts.** If you don't give it a phone number, an AI may make one up. Same with an address, hours, reviews or a "since 1998". A made-up fact on a business website is worse than a blank. The `CLAUDE.md` in this kit forbids it.
